# HookForge

HookForge is a premium creator ops suite that turns a single brief into a week of scroll‑stopping content. It helps creators, influencers, and operator‑brands ship hooks, threads, and calendars faster, with a polished, on‑brand voice.

Built for speed, clarity, and consistency, HookForge is the content engine that keeps your output flowing — every week.

Local secrets are expected at `C:\\Users\\Shango\\.codex\\memories\\launch-secrets\\hookforge.env.local`
or another path provided through `HOOKFORGE_ENV_FILE`. The repo copy of `.env.local`
is intentionally inert so secrets do not sit inside the working tree.
